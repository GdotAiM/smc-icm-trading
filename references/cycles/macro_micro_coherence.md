# Macro-Micro Coherence — The Alignment Rules

Coherence measures how well the LTF picture confirms the HTF thesis. High coherence = high probability. Low coherence = stay out.

## Coherence Score (0-10)

```
1. LTF BIAS ALIGNMENT (0-3 points)
   Are 15m, 5m, and 1m aligned with HTF direction?
   +1 for each LTF that matches HTF bias
   If HTF is neutral, score 1 point for any LTF with clear bias

2. LTF STRUCTURE (0-2 points)
   Is there a recent BOS or CHoCH on LTF in HTF direction?
   +2 if 15m or 5m BOS in HTF direction
   +1 if 15m or 5m CHoCH in HTF direction  
   +0 if no structure event or event is opposite

3. LTF DISPLACEMENT (0-2 points)
   Is there active displacement on the entry timeframe?
   +2 if 5m displacement is moderate or strong in HTF direction
   +1 if 5m displacement is weak but in HTF direction
   +0 if no displacement or displacement is opposite

4. LTF MANIPULATION (0-2 points)
   Has there been a recent sweep confirming HTF direction?
   +2 if 15m/5m sweep in the direction OPPOSITE to HTF (manipulation trap)
   +1 if sweep detected but ambiguous direction
   +0 if no sweep

5. TRIGGER READINESS (0-1 point)
   Is there a valid entry trigger RIGHT NOW?
   +1 if 5m FVG present + 1m CHoCH in HTF direction
   +0 otherwise
```

## Interpretation

| Score | Label | Action |
|-------|-------|--------|
| **9-10** | Perfect Coherence | ENTER — textbook setup, full size |
| **7-8** | High Coherence | ENTER — standard size |
| **5-6** | Moderate Coherence | WAIT — let LTF develop further, or reduce size 50% |
| **3-4** | Low Coherence | WAIT — LTF not confirming, check again in 15-30 min |
| **0-2** | No Coherence | NO TRADE — LTF contradicts HTF, thesis may be wrong |

## Common Coherence Patterns

### Pattern 1: Textbook Continuation (Score 9-10)
```
HTF 1D:  BEARISH Distribution
15m:     BEARISH BOS — price making lower lows
5m:      BEARISH CHoCH — just broke structure down
1m:      BEARISH — displacement active
Sweep:   BSL swept on 5m before the CHoCH
FVG:     Bearish FVG on 5m, unfilled, 3 pips wide
→ Score: 3+2+2+2+1 = 10/10 — ENTER
```

### Pattern 2: Pullback Within Trend (Score 3-5)
```
HTF 1D:  BEARISH Distribution
15m:     BULLISH CHoCH — counter-trend bounce
5m:      BULLISH — making higher highs
1m:      BULLISH — strong displacement up
Sweep:   None
FVG:     Bullish FVG on 5m  
→ Score: 0+0+0+0+0 = 0/10 initially, then 5m flips bearish → 7/10
→ Action: WAIT for 5m to resume bearish, then enter
```

### Pattern 3: The Manipulation Trap (Score 8-10)
```
HTF 1W:  BULLISH (macro trend)
HTF 1D:  BEARISH (daily pullback = manipulation)
15m:     SSL sweep below recent swing + BULLISH CHoCH reversal
5m:      BULLISH BOS — breaking higher
1m:      BULLISH — displacement active
Sweep:   SSL swept on 15m (the manipulation)
FVG:     Bullish FVG on 5m after the sweep
→ Score: 3+2+1+2+1 = 9/10 — TEXTBOOK manipulation entry
→ This is the highest-probability ICT setup
```

### Pattern 4: False Signal (Score 0-2)
```
HTF 1D:  BEARISH Distribution
15m:     BULLISH BOS — looks like a reversal
5m:      BULLISH BOS — confirming 15m
1m:      BULLISH — strong displacement
Sweep:   SSL swept (bullish signal)
FVG:     Bullish FVG
→ Score: 0+0+0+0+0 = 0/10 for a SHORT
→ This looks bullish but HTF is bearish — this is a TRAP
→ If you go long here, you're fighting the daily trend
→ The "bullish reversal" is actually just a pullback before the next leg down
```

## The Golden Rule

**LTF can NEVER override HTF.** If the daily says bearish, no amount of 1m bullish signals makes a valid long. The LTF bullish move is either:
1. A pullback to sell into (better short entry), or
2. The start of a macro reversal (needs daily confirmation first)

Only when the DAILY flips does the macro thesis change. Until then, LTF counter-trend moves are opportunities, not reversals.
